    - 核心用户：经常忘记账号密码、有安全焦虑的个人用户。
    - 核心机制：“部分输入解锁”（Partial Input Unlock）。用户录入N个账号密码后，系统允许用户尝试M次（例如30次），用户只需正确回忆并输入其中K个（例如5个），即可解锁查看全部数据。

    - 用户是个人消费者，非企业用户。
    - 用户对自己设定的密码有“部分记忆”能力。
