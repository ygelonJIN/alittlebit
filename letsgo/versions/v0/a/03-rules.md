## 15. 不确定性处理原则
- 信息不足时：优先追问，不假设
- 输入存在歧义时：先澄清再继续
- 用户暂时无法决定时：提供选项并标明推荐
- 系统推断项：必须显式标记，不得自动升级为确认
- 冲突内容：优先采用更接近执行层的约束

## 16. 版本治理规则
- 初始输入形成版本 v0
- 版本只能通过派生产生，不得覆盖历史版本
- 锁定版本不可直接修改
- 归档版本只读保留
- 每次变更必须可追溯
- 每次变更必须同步差异文件与索引
- 每个版本必须保留版本摘要、日志与确认记录

## 17. 文档同步规则
- 改 PRD 要检查 Features
- 改 Features 要检查 Rules 和 RFC
- 改 Rules 要检查实施与审查约束
- 改 RFC 要检查实施、测试与变更管理
- 改实现要回写审查与测试结果
- 改任何正式内容都必须记录变更
