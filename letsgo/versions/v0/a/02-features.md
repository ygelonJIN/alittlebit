## 2. 系统模块划分
基于 PRD 技术架构（前端画布 + Electron + Python 引擎），按模块能力拆分为以下四个核心模块：
- **前端画布模块**：负责可视化工作流编辑、节点交互、连线、配置面板、调试面板。
- **执行引擎模块**：负责解析工作流 JSON、DAG 调度、拓扑排序、节点执行与状态管理、每步留痕与结果验证。
- **定位策略模块**：封装策略1（坐标）、策略2（OpenCV图像匹配）、策略3（YOLO推理）、策略4（OCR文字定位）、策略5（多模态API），每策略独立功能点，支持级联与并行模式。
- **通信管理模块**：负责 Electron 主进程与 Python 子进程间的 JSON 协议通信、日志与进度回传。
## 3. 核心功能清单
### F-001: 可视化画布
- 业务逻辑: 支持无限画布拖拽，节点自由摆放，连线自动吸附端口。用户可从工具栏拖入节点类型、连接节点端口、缩放/平移画布、撤销/重做操作。画布状态可序列化为管线 JSON。
- 依赖项: 无
- 边界与异常: 画布为空时展示引导提示；连线形成循环依赖时实时标红提示并阻止连接；节点数量超过性能阈值时启用虚拟化渲染
- 技术约束: 基于 React Flow (@xyflow/react) 实现，画布状态可序列化/反序列化为 JSON

### F-002: 节点配置面板
- 业务逻辑: 每个节点内嵌独立配置面板，根据节点类型展示不同配置项。配置内容包括：策略选择（启用/禁用每层策略）、置信度阈值（滑块 0-100%，默认 60%）、超时策略、级联/并行模式选择。
- 依赖项: F-001
- 边界与异常: 配置项为空时使用默认值（阈值 60%、级联模式）；非法配置（如阈值超出范围）实时校验提示；配置变更实时同步到节点 JSON
- 技术约束: 配置面板为 React 组件嵌入节点，配置数据序列化为节点 JSON 的一部分

### F-003: 调试面板
- 业务逻辑: 执行时展示执行步骤列表，每步包含：步骤截图、匹配位置高亮、置信度数值。用户可逐步回放、点击步骤定位到对应节点、暂停/继续执行。验证失败时自动暂停并展开调试面板。
- 依赖项: F-001
- 边界与异常: 截图加载失败时显示占位图；步骤数量过多时虚拟滚动；执行中断时保留已执行步骤数据供回溯
- 技术约束: 截图数据通过 stdout JSON 从 Python 引擎实时回传，面板支持实时更新

### F-004: 工作流持久化
- 业务逻辑: 支持本地保存工作流为 JSON 文件，支持从本地文件加载工作流到画布。保存内容包括画布状态、所有节点配置、连线关系。不支持在线分享或导出为其他格式。
- 依赖项: F-001
- 边界与异常: 文件损坏时提示错误并保留当前画布状态；文件版本不兼容时提示升级；保存时自动校验 JSON 完整性
- 技术约束: 文件格式为 JSON，使用 Electron 文件系统 API 进行本地读写
